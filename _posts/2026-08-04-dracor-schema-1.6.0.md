excerpt: >
  The DraCor Schema 1.6.0 now supports TEI version 4.12.0.
---

Following the release of
[TEI 4.12.0](https://tei-c.org/release//doc/tei-p5-doc/readme-4.12.0.html) the
DraCor Schema is now based on the latest TEI version. We also added a few more
markup option. See the
[release notes](https://github.com/dracor-org/dracor-schema/releases/tag/1.6.0) for details.

We also updated the
[DraCor Validate Action](https://github.com/dracor-org/dracor-validate-action/releases/tag/2.6.0)
and the
[DraCor Oxygen Framework](https://github.com/dracor-org/dracor-oxygen-framework/releases/tag/1.2.0).
The latter now includes transformation scenarios for migrating corpora to the
latest schema version.
